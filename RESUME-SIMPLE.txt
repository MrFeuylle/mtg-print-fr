⚔️ MTG PRINT FR - CE QUI A ÉTÉ CRÉÉ

═══════════════════════════════════════════════════════════════════

✅ VOUS AVEZ UNE APP COMPLÈTE!

Une application web React qui:
  ✅ Convertit votre decklist MTG en images
  ✅ Génère un PDF prêt à imprimer
  ✅ 100% dans le navigateur (aucun serveur)
  ✅ Prête pour GitHub Pages (gratuit)

═══════════════════════════════════════════════════════════════════

🎯 COMMENT ÇA MARCHE?

1. Vous collez votre decklist:
   "4 Foudre
    3 Contresort"

2. L'app cherche les images sur Scryfall API

3. L'app affiche une grille de cartes

4. L'app génère un PDF (grille 3×3 = 9 cartes par page)

5. Le PDF se télécharge sur votre ordinateur

✅ Prêt à imprimer!

🚀 3 ÉTAPES POUR COMMENCER:

ÉTAPE 1: Installer Node.js
  → https://nodejs.org
  → Version LTS
  → Installez normalement
  → Redémarrez votre terminal

ÉTAPE 2: Lancer l'app
  → Double-cliquez: start-dev.bat
  → OU tapez: npm install && npm run dev

ÉTAPE 3: Tester
  → Ouvrez: http://localhost:5173/
  → Collez une decklist
  → Cliquez "Prévisualiser"
  → Cliquez "Télécharger PDF"
  → ✅ C'est fini!
