🆘 TROUBLESHOOTING:

"npm: command not found"
→ Node.js n'est pas installé correctement
→ Téléchargez depuis: https://nodejs.org
→ Redémarrez votre PowerShell après installation

"Port 5173 already in use"
→ Utilisez un autre port: npm run dev -- --port 3000

"Carte non trouvée"
→ Vérifiez l'orthographe exacte
→ Certaines cartes n'existent que en anglais sur Scryfall

"PDF vide"
→ Attendez que les images se chargent complètement
→ Vérifiez la grille d'aperçu
