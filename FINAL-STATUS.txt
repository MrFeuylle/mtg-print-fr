🔍 FLUX DE DONNÉES (RÉSUMÉ):

User colles decklist
    ↓
parseDeckList() → [{qty: 4, name: "Foudre"}, ...]
    ↓
validateDeckList() → errors[] ou OK
    ↓
searchCards() → Scryfall API
    ↓
Résultats: {name, imageUrl, scryfallId}
    ↓
Expand by qty: [img1, img2, img3, ...]
    ↓
Preview: grille 3×3
    ↓
User clique "Download PDF"
    ↓
convertImageToBase64() → ArrayBuffers
    ↓
generatePDF() → pdf-lib
    ├── Create A4 document
    ├── Layout 3×3 (9 cards/page)
    ├── Embed images
    └── Save bytes
    ↓
downloadPDF() → Téléchargement ✅

🆘 SUPPORT & TROUBLESHOOTING:

Problème: Node.js introuvable
Cause: Pas installé ou pas dans PATH
Solution: Téléchargez https://nodejs.org et réinstallez

Problème: Port 5173 en utilisation
Solution: npm run dev -- --port 3000

Problème: Carte non trouvée
Solution: Vérifiez l'orthographe sur Scryfall

Problème: PDF vide
Solution: Attendez que les images se chargent

Problème: GitHub Pages ne se met à jour pas
Solution: Attendez 1-2 minutes, rafraîchissez la page

Pour plus de détails: consultez INSTALLATION.md
